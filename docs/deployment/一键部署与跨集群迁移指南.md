# K8sOperation 一键部署与跨集群迁移指南

## 目录结构

```
deploy/
├── kustomization.yaml          # 顶层：前端+后端一起部署
├── backend/                    # 后端（namespace: k8soperation）
│   ├── kustomization.yaml
│   ├── namespace.yaml          # Namespace 定义
│   ├── secret.yaml             # 敏感配置（DB/Redis/JWT/Jenkins 等）
│   ├── configmap.yaml          # 主配置文件（config.yaml）
│   ├── pv.yaml                 # PV（开发环境 hostPath，生产环境替换）
│   ├── pvc.yaml                # PVC
│   ├── service.yaml            # ClusterIP Service + ServiceAccount + RBAC
│   ├── service-nodeport.yaml   # NodePort（可选）
│   ├── deployment.yaml         # 主 Deployment（含 initContainer 修复权限）
│   └── ingress.yaml            # Ingress（可选）
├── frontend/                   # 前端（namespace: k8soperation）
│   ├── kustomization.yaml
│   ├── configmap.yaml          # Nginx 配置（反向代理后端）
│   ├── deployment.yaml         # 前端 Deployment
│   ├── service.yaml            # ClusterIP Service
│   ├── service-nodeport.yaml   # NodePort（可选）
│   └── ingress.yaml            # Ingress（可选）
└── jenkins/                    # Jenkins CI/CD（namespace: devops）
    ├── kustomization.yaml
    ├── namespace.yaml
    ├── rbac.yaml               # ServiceAccount + ClusterRole
    ├── secret.yaml             # Jenkins 密码、HMAC、SonarQube Token
    ├── pvc.yaml                # 数据 + 各语言构建缓存
    ├── configmap.yaml          # JCasC 配置（K8s Cloud、凭证、SonarQube）
    ├── statefulset.yaml        # Jenkins Master
    └── service.yaml            # ClusterIP + Agent + NodePort
```

## 一键部署命令

### 方式一：前端 + 后端一起（推荐）

```bash
kubectl apply -k deploy/
```

### 方式二：分模块独立部署

```bash
# 后端（namespace: k8soperation）
kubectl apply -k deploy/backend/

# 前端（namespace: k8soperation）
kubectl apply -k deploy/frontend/

# Jenkins（namespace: devops，独立部署）
kubectl apply -k deploy/jenkins/
```

### 删除部署

```bash
kubectl delete -k deploy/backend/
kubectl delete -k deploy/frontend/
kubectl delete -k deploy/jenkins/
```

## 本地开发环境部署（Docker Desktop K8s）

### 前提条件

- Docker Desktop 已启用 Kubernetes
- 本地已有 MySQL 和 Redis 服务

### 后端镜像构建

```bash
# 在项目根目录构建
docker build -f docker/backend/Dockerfile -t k8soperation:local .
```

### 关键配置说明

| 配置项 | 当前值 | 说明 |
|--------|--------|------|
| 后端镜像 | `k8soperation:local` | 本地构建，不需拉取 |
| imagePullPolicy | `IfNotPresent` | 使用本地缓存镜像 |
| DB_HOST | `host.docker.internal` | Docker Desktop 宿主机访问 |
| REDIS_ADDRESS | `host.docker.internal:6380` | Docker Desktop 宿主机访问 |
| PV 类型 | `hostPath` | 仅适用本地开发 |
| initContainer | 使用 `k8soperation:local` 镜像 | 修复 hostPath 目录权限 |

### 已知问题与解决方案

1. **日志 `permission denied`**：容器以 app(UID=1000) 运行，hostPath 目录由 kubelet(root) 创建 → initContainer 以 root 身份 `chown -R 1000:1000` 修复
2. **Docker Desktop `fsGroup` 对 hostPath 不生效**：这是已知限制，必须用 initContainer 方案
3. **busybox/alpine 镜像拉取慢**：initContainer 直接复用 `k8soperation:local`（已在本地缓存）

## 跨集群迁移配置修改清单

> 将项目从本地 Docker Desktop 迁移到生产/测试集群时，需要修改的配置项。

### 一、后端 - 镜像相关

| 文件 | 配置项 | 当前值 | 修改为 |
|------|--------|--------|--------|
| `deploy/backend/deployment.yaml` | initContainer image (第39行) | `k8soperation:local` | 远程仓库地址 或 `busybox:1.36`（生产集群通常能拉取） |
| `deploy/backend/deployment.yaml` | container image (第52行) | `k8soperation:local` | `your-registry.com/k8soperation:v1.0` |
| `deploy/backend/deployment.yaml` | imagePullPolicy | `IfNotPresent` | 保持或改为 `Always`（配合 latest tag） |
| `deploy/frontend/deployment.yaml` | image | `registry.cn-hangzhou.aliyuncs.com/k8s-gos/devops-fe:latest` | 你实际推送的前端镜像地址 |

### 二、后端 - 数据库配置

| 文件 | Key | 当前值 | 修改为 |
|------|-----|--------|--------|
| `deploy/backend/secret.yaml` | DB_HOST | `host.docker.internal` | 新集群可达的 MySQL 地址 |
| `deploy/backend/secret.yaml` | DB_PORT | `3307` | 实际端口（通常 3306） |
| `deploy/backend/secret.yaml` | DB_PASSWORD | `admin123` | 生产密码 |
| `deploy/backend/secret.yaml` | DB_NAME | `k8s-platform` | 按需修改 |

### 三、后端 - Redis 配置

| 文件 | Key | 当前值 | 修改为 |
|------|-----|--------|--------|
| `deploy/backend/secret.yaml` | REDIS_ADDRESS | `host.docker.internal:6380` | 新集群可达的 Redis 地址 |
| `deploy/backend/secret.yaml` | REDIS_PASSWORD | `admin123` | 生产密码 |

### 四、后端 - 安全密钥（必须修改！）

| 文件 | Key | 当前值 | 修改建议 |
|------|-----|--------|----------|
| `deploy/backend/secret.yaml` | JWT_SIGNING_KEY | `eoNB0%bv5M7995F1` | 生成 32 位随机字符串 |
| `deploy/backend/secret.yaml` | HMAC_SECRET | `changeme` | 与 Jenkins secret 中 `hmac-secret` 保持一致 |
| `deploy/backend/secret.yaml` | KUBECONFIG_ENCRYPT_KEY | `changemp` | 生成 16/32 位 AES 密钥 |
| `deploy/backend/secret.yaml` | CACHE_SECRET | `k8smana` | 生成随机字符串 |

### 五、后端 - Jenkins 集成

| 文件 | Key | 当前值 | 修改为 |
|------|-----|--------|--------|
| `deploy/backend/secret.yaml` | JENKINS_URL | `http://jenkins.devops.svc.cluster.local:8080/` | 若 Jenkins 不在同集群改为外部地址 |
| `deploy/backend/secret.yaml` | JENKINS_USERNAME | `ops-dev` | 新 Jenkins 的用户名 |
| `deploy/backend/secret.yaml` | JENKINS_API_TOKEN | `1189c229...` | 新 Jenkins 生成的 API Token |
| `deploy/backend/secret.yaml` | GIT_CREDENTIAL_ID | `gitee-id` | Jenkins 中实际的 Git 凭证 ID |
| `deploy/backend/secret.yaml` | REGISTRY_CREDENTIAL_ID | `harbor-registry` | Jenkins 中实际的镜像仓库凭证 ID |

### 六、后端 - 通知与前端地址

| 文件 | Key | 当前值 | 修改为 |
|------|-----|--------|--------|
| `deploy/backend/secret.yaml` | PLATFORM_FRONTEND_URL | `http://localhost:5173` | 前端实际域名/IP |
| `deploy/backend/secret.yaml` | ENABLE_DINGTALK | `true` | 按需 |
| `deploy/backend/secret.yaml` | DINGTALK_WEBHOOK | 空 | 实际的钉钉 Webhook URL |

### 七、后端 - 存储（⚠️ 最大改动）

| 文件 | 当前方式 | 生产方案 |
|------|----------|----------|
| `deploy/backend/pv.yaml` | `hostPath: /data/k8soperation/...` | **删除此文件**，使用 StorageClass 动态供给 |
| `deploy/backend/pvc.yaml` | `storageClassName: ""` | 改为 `storageClassName: your-sc-name` |
| `deploy/backend/kustomization.yaml` | 包含 `- pv.yaml` | 删除该行（PV 由 StorageClass 自动创建） |
| `deploy/backend/deployment.yaml` | initContainer fix-permissions | 如果 StorageClass 支持 fsGroup **可删除 initContainer** |

### 八、镜像拉取凭证

```bash
# 在目标集群创建 imagePullSecret
kubectl -n k8soperation create secret docker-registry aliyun-registry \
  --docker-server=your-registry.com \
  --docker-username=your-user \
  --docker-password=your-password

# Jenkins namespace 也需要（如果 Jenkins 用私有镜像）
kubectl -n devops create secret docker-registry aliyun-registry \
  --docker-server=your-registry.com \
  --docker-username=your-user \
  --docker-password=your-password
```

### 九、Jenkins 配置

| 文件 | Key | 修改说明 |
|------|-----|----------|
| `deploy/jenkins/secret.yaml` | admin-password (base64) | `echo -n "新密码" \| base64` |
| `deploy/jenkins/secret.yaml` | hmac-secret (base64) | 与后端 HMAC_SECRET 一致，base64 编码 |
| `deploy/jenkins/secret.yaml` | sonarqube-token (base64) | SonarQube 生成的实际 Token |
| `deploy/jenkins/configmap.yaml` | sonarqube serverUrl | 改为实际 SonarQube 地址 |
| `deploy/jenkins/pvc.yaml` | storageClassName | 生产环境指定 StorageClass |

### 十、前端配置

| 文件 | 配置项 | 修改说明 |
|------|--------|----------|
| `deploy/frontend/deployment.yaml` | imagePullSecrets | 确保新集群有对应 Secret |
| `deploy/frontend/configmap.yaml` | upstream backend server | 后端 Service 地址（同集群内默认不用改） |
| `deploy/frontend/ingress.yaml` | host | 改为实际域名 |

## 生产集群完整部署步骤

```bash
# ============ 1. 构建并推送镜像 ============
# 后端
docker build -f docker/backend/Dockerfile -t your-registry.com/k8soperation:v1.0 .
docker push your-registry.com/k8soperation:v1.0

# 前端
cd k8s-web
docker build -f ../docker/frontend/Dockerfile -t your-registry.com/devops-fe:v1.0 .
docker push your-registry.com/devops-fe:v1.0

# ============ 2. 修改配置文件 ============
# 按上方清单修改 secret.yaml、deployment.yaml、pv.yaml 等

# ============ 3. 创建 Namespace 和 Secret ============
kubectl apply -f deploy/backend/namespace.yaml

# 创建镜像拉取凭证
kubectl -n k8soperation create secret docker-registry aliyun-registry \
  --docker-server=your-registry.com \
  --docker-username=xxx \
  --docker-password=xxx

# ============ 4. 一键部署 ============
kubectl apply -k deploy/backend/
kubectl apply -k deploy/frontend/
kubectl apply -k deploy/jenkins/    # 如需 Jenkins

# ============ 5. 验证 ============
kubectl -n k8soperation get pods
kubectl -n k8soperation logs -f deployment/k8soperation
kubectl -n devops get pods          # Jenkins
```

## 快速生成密钥命令

```bash
# JWT 签名密钥（32位）
openssl rand -base64 32

# HMAC 密钥
openssl rand -hex 16

# KubeConfig 加密密钥（AES-256 需要 32 字节）
openssl rand -base64 32

# base64 编码（Jenkins secret 用）
echo -n "your-password" | base64
```
