# K8sOperation 虚拟机直接部署指南

> 本文档适用于不使用 Docker/Kubernetes，直接在 Linux 虚拟机上部署 K8sOperation 平台的场景。

---

## 一、环境要求

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| 操作系统 | CentOS 7+ / Ubuntu 20.04+ | 推荐 CentOS 8 或 Ubuntu 22.04 |
| MySQL | 8.0+ | 存储平台数据 |
| Redis | 6.0+ | 会话缓存 |
| Nginx | 1.18+ | 前端静态文件 + 反向代理 |
| Node.js | 20.19+ 或 22.12+ | 仅编译前端时需要 |
| Go | 1.21+ | 仅编译后端时需要（也可本地交叉编译） |

---

## 二、目录规划

```
/opt/k8soperation/
├── k8soperation              # 后端二进制
├── configs/
│   ├── config.yaml           # 主配置文件
│   └── k8s.yaml              # K8s 集群 kubeconfig
├── storage/
│   └── logs/                 # 运行日志
└── frontend/
    └── dist/                 # 前端静态文件
```

---

## 三、安装基础依赖

### CentOS / RHEL

```bash
# MySQL 8
yum install -y mysql-server
systemctl enable --now mysqld

# Redis
yum install -y redis
systemctl enable --now redis

# Nginx
yum install -y nginx
systemctl enable --now nginx
```

### Ubuntu / Debian

```bash
# MySQL 8
apt update && apt install -y mysql-server
systemctl enable --now mysql

# Redis
apt install -y redis-server
systemctl enable --now redis-server

# Nginx
apt install -y nginx
systemctl enable --now nginx
```

## 四、初始化数据库

### 4.1 创建数据库

```bash
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS \`k8s-platform\` DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

### 4.2 导入表结构

项目提供了完整的 SQL 初始化脚本：

```bash
mysql -u root -p --default-character-set=utf8mb4 < docs/sql/k8s_platform_full_init.sql
```

或使用项目自带的初始化脚本（交互式）：

```bash
DB_HOST=127.0.0.1 DB_PASS=your_password bash scripts/init-db.sh
```

> 默认管理员账号：`admin` / `admin123`

## 五、编译后端

### 方式一：本地交叉编译（推荐，在开发机 macOS/Windows 上执行）

```bash
# 编译 Linux amd64 二进制
GOOS=linux GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o bin/k8soperation-linux ./cmd/k8soperation
```

### 方式二：在虚拟机上直接编译

```bash
# 安装 Go（如未安装）
wget https://go.dev/dl/go1.22.4.linux-amd64.tar.gz
tar -C /usr/local -xzf go1.22.4.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin

# 编译
cd /path/to/k8s_operation-main
make build
```

## 六、编译前端

```bash
cd k8s-web

# 安装依赖
npm install

# 构建生产版本
npm run build
```

构建产物在 `k8s-web/dist/` 目录。

## 七、部署文件上传

将以下文件传到虚拟机：

```bash
# 后端二进制
scp bin/k8soperation-linux user@VM_IP:/opt/k8soperation/k8soperation

# 配置文件
scp configs/config.yaml user@VM_IP:/opt/k8soperation/configs/
scp configs/k8s.yaml user@VM_IP:/opt/k8soperation/configs/

# 前端
scp -r k8s-web/dist/ user@VM_IP:/opt/k8soperation/frontend/dist/
```

在虚拟机上设置权限：

```bash
chmod +x /opt/k8soperation/k8soperation
mkdir -p /opt/k8soperation/storage/logs
```

## 八、修改配置文件

编辑 `/opt/k8soperation/configs/config.yaml`，根据实际环境修改：

```yaml
Server:
  RunMode: release          # 生产环境改为 release
  Port: 8080

Database:
  Host: 127.0.0.1           # MySQL 地址
  Port: 3306
  Username: root
  Password: "your_mysql_password"
  DBName: k8s-platform

Cache:
  Address: 127.0.0.1:6379   # Redis 地址
  Username: ""               # Redis 6+ 无用户名则留空
  Password: "your_redis_password"

App:
  LogLevel: info             # 生产环境用 info 或 warn
  GlobalKubeConfigPath: /opt/k8soperation/configs/k8s.yaml
  AllowEmptyStart: true      # 无 K8s 集群时允许空启动

ErrorCode:
  AllowOverride: true

LDAP:
  Enabled: false             # 不使用 LDAP 时关闭
```

## 九、配置 systemd 服务

创建服务文件 `/etc/systemd/system/k8soperation.service`：

```ini
[Unit]
Description=K8sOperation Platform
After=network.target mysql.service redis.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/k8soperation
Environment=APP_CONFIG=/opt/k8soperation/configs/config.yaml
Environment=GIN_MODE=release
ExecStart=/opt/k8soperation/k8soperation
Restart=always
RestartSec=5
LimitNOFILE=65536

# 日志输出到 journald
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
systemctl daemon-reload
systemctl enable --now k8soperation

# 查看状态
systemctl status k8soperation

# 查看日志
journalctl -u k8soperation -f
```

## 十、配置 Nginx 反向代理

创建配置 `/etc/nginx/conf.d/k8soperation.conf`：

```nginx
server {
    listen 80;
    server_name your-domain.com;    # 改为你的域名或 IP

    # 前端静态文件
    location / {
        root /opt/k8soperation/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }

    # WebSocket 代理（终端、日志流）
    location /ws/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 3600s;
    }

    # Swagger 文档（可选）
    location /swagger/ {
        proxy_pass http://127.0.0.1:8080;
    }
}
```

验证并重载：

```bash
nginx -t
systemctl reload nginx
```

## 十一、防火墙配置

```bash
# CentOS (firewalld)
firewall-cmd --permanent --add-port=80/tcp
firewall-cmd --permanent --add-port=443/tcp
firewall-cmd --reload

# Ubuntu (ufw)
ufw allow 80/tcp
ufw allow 443/tcp
```

## 十三、运维命令

```bash
# 查看后端日志
journalctl -u k8soperation -f --no-pager

# 重启后端
systemctl restart k8soperation

# 查看应用日志
tail -f /opt/k8soperation/storage/logs/app.log

# 更新部署（上传新二进制后）
systemctl stop k8soperation
cp k8soperation-linux-new /opt/k8soperation/k8soperation
chmod +x /opt/k8soperation/k8soperation
systemctl start k8soperation
```
