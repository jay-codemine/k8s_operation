## 🔧 技术细节

### Maven 镜像 Java 版本说明

**重要变更**：Maven 镜像从动态版本改为固定 Java 17

- **旧配置**：`maven:3.9-eclipse-temurin-${params.JAVA_VERSION ?: '17'}`（支持 Java 8/11/17/21）
- **新配置**：`maven:3.9.9-eclipse-temurin-17-noble`（固定 Java 17）

**原因**：
1. Java 17 向后兼容 Java 8/11 编译的代码
2. 支持 Spring Boot 3.x（需要 Java 17+）
3. 更现代的编译器，更好的性能

**影响**：
- ✅ Java 8/11/17 项目均可正常编译
- ⚠️ 如果需要 Java 21，需要单独配置 maven 镜像

### imagePullPolicy 保持 Always

所有 Pipeline 模板继续使用 `imagePullPolicy: Always` 策略，确保：
- 始终拉取最新镜像
- 避免 K8s 节点缓存导致架构不匹配
- 解决之前出现的 `exec format error` 问题

## ⚠️ 注意事项

### Jenkins Pipeline 构建
- 下次触发 Jenkins Pipeline 构建时，会自动使用新的华为云 SWR 镜像
- 无需手动修改 Jenkins Job 配置
- Pod Agent 容器会使用 `imagePullPolicy: Always` 强制拉取

### 已有 Pod 不受影响
- 已运行的 Jenkins Pipeline Pod 不会自动更新
- 只有新建的 Pod 才会使用新镜像

### 镜像拉取认证
- 确保 K8s 集群已配置 `aliyun-registry` imagePullSecret
- 华为云 SWR 镜像为公开镜像，无需额外认证
